# ぐるりエディタ修正

`app.js` と `style.css` を `src/tools/gururi-editor-dev/` に上書きします。

- ダイアローグを作成した時点で1ページ目を生成
- ダイアローグ追加ボタンをページ一覧の末尾へ移動し、名称を「ダイアローグを追加」へ変更
- カメラ情報の折りたたみ見出しを `▶ カメラ情報` としてレイヤー欄とは別デザインへ
- キーフレームの再生時間と現在の時間を数値入力できるよう変更

`node --check .\src\tools\gururi-editor-dev\app.js`
`node scripts/deploy.js --editor-dev`

キーフレームの最終登録時刻より短い再生時間は設定できません。以前作成したダイアローグでページ数が0の場合は、新規ノードだけではなく、編集時にも先頭ページを補う必要がある場合があります。
