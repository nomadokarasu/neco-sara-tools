WEB DEVELOPMENT

コード統合ツール

フォルダ内のコードを、ひとつのテキストファイルにまとめるWebツールです。 AIとのコード共有にお使いください。

ツールを起動

できること

プロジェクトフォルダを選択すると、その中にあるコードファイルを読み込み、 ひとつのテキストとしてまとめます。

AIとのコーディングでプロジェクト全体のコードを共有したいときなどに利用できます。

使い方

  1. 「フォルダを選択」を押します。
  2. まとめたいプロジェクトフォルダを選択します。
  3. 対象となるファイルを確認します。
  4. テキストファイルとして保存します。

プライバシー

選択したファイルは利用者のブラウザ内で処理されます。 ファイルの内容をこのサイトのサーバーへアップロードすることはありません。
