# ぐるりコレクション v0

ゼロから作り直した初期UIです。

## 現在できること
- PC / スマホ対応のレスポンシブUI
- おすすめ作品カード表示
- BOOTHへの外部リンク
- 「すべて / 画像 / 動画 / ゲーム」カテゴリーUI
- 検索UI
- 仮の作品追加
- 作品一覧表示
- Viewer Coreを後から接続するための鑑賞画面

## まだ実装していないこと
- .gururiart の正式な解析
- 作品の永続保存
- 360°静止画Viewer
- サムネイル生成
- おすすめ作品のオンラインJSON取得
- HMD / WebXR対応

## 将来構造
Viewer Coreを共通化し、
- illustration player
- animation player
- game player

を切り替える構成を想定しています。

HMD対応はViewer Coreの入力・表示レイヤーとして追加し、
作品データ形式を変更せず対応できる設計を目指します。

## PWA・プライバシー追加仕様
- HTTPSの同一ディレクトリにファイル一式をアップロードしてください（localhostでもテスト可能）。
- ぐるりペイントの作品ZIP（`manifest.json`とPNG/MP4）の処理とIndexedDB保存はブラウザ内で行います。サイトへのHTTPアクセスやおすすめ作品のBOOTHリンクなどは別途通信を伴います。
- Service Workerはアプリの静的ファイルのみキャッシュします。ユーザー作品は従来通りIndexedDBに保存されます。
- Androidでインストール画面を安定して表示するには、192px/512pxのアプリアイコンを用意し、manifest.webmanifestにicons項目を追加してください。今回は画像を新規作成していません。
- 実機テスト: HTTPS接続→作品登録→機内モード→再起動→鑑賞→バックアップ→復元。iPhone/Android両方で動作確認してください。
- アプリのURLが変わるとブラウザ内に保存した作品を引き継げない場合があります。
