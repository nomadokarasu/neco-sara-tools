WEB DEVELOPMENT

Webツール公開システム

AIと協働して作ったWebツールを、 マスターデータからビルドし、 GitHub経由で自動公開・更新するための仕組みです。

この仕組みについて

AIとの協働でWebツールを継続的に制作・公開していくために作った、 自分用の公開システムです。

ツールのマスターデータと実際に公開するデータを分離し、 GitHubへ更新を送ることで、 公開サイトまで自動的に反映される構成にしています。

仕組み

  1. src にあるマスターデータを編集します。
  2. ビルド処理によって dist に公開用データを生成します。
  3. Gitで変更履歴を記録し、GitHubへpushします。
  4. GitHub Actionsが自動的に公開用データを生成します。
  5. 生成されたデータをFTPSでWebサーバーへアップロードします。

更新の流れ

普段の更新では、サーバー上のファイルを直接編集しません。 マスターデータを変更し、その変更から公開用データを作ります。

  1. src内のファイルを編集
  2. ローカルでビルド
  3. distの内容を確認
  4. Gitへコミット
  5. GitHubへpush
  6. GitHub Actionsが自動ビルド
  7. Webサーバーへ自動反映

構成

この公開システムでは、主に次の構成でデータを管理しています。 

neco-sara-tools/
├─ src/          マスターデータ
├─ dist/         公開用データ
├─ scripts/      ビルド処理
├─ .github/
│  └─ workflows/ 自動公開設定
└─ package.json
